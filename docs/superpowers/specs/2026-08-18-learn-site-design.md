# learn/ 教学站(闯关式课程)· 设计

日期:2026-08-18。状态:已获用户口头批准(方案 A + 全部推荐项),待书面确认。
承接:2026-07-24 explainer 设计(explainer 定位为「介绍站」,本站为「教学站」,互不替代)。

## 背景与动机

`learn/*.md` 四卷(game/network/mcts/flywheel)经 11 轮评审达到 S 级,但仍被用户判定为「不是完全不懂神经网络就能读懂的文章」——决策链式散文对零基础读者的认知负载仍过高。决定:

1. **归档** `learn/*.md` → `learn/archive/`(文案母本,不删除);
2. 在 `learn/` 下新建**闯关式教学前端**,以「不懂神经网络的人也能看明白并学会整个思路,知其然并知其所以然」为目标。

与 explainer 的差异:explainer 是介绍站(看完知道它做了什么);本站是教学站(学完能讲清为什么这么设计)。核心教学论:**卡→通节拍**——每个概念先让读者在谜题上卡一下(体验到「不会」),再揭晓机制(体验到「原来如此」),线性闯关 + 小测门禁物理上防止滑读。

## 形态

- `learn/` 目录下的独立 Vite SPA(React 19 + Vite 6 + TS + Tailwind 4),零后端、纯静态、离线可用,构建产物随仓走;
- package.json / vite.config / tsconfig 独立,不与 explainer、web 共享代码;
- 设计语言沿用 explainer 打磨过的:暖纸/墨黑/朱砂/等宽数字/手绘 SVG/无图表库/无 emoji;
- 进度纯 localStorage,无账号无后端。

## 课程地图(序 + 9 课 + 毕业沙盒,共 11 节点)

| 节点 | 谜题(卡点) | 可玩部件(读者亲手操作) |
|---|---|---|
| 序 | 没人教过它一盘棋,它怎么会的? | 真模型对弈回放(best.pt 在浏览器跑前向) |
| 1 棋盘 | 计算机眼里这盘棋长什么样? | 点格子→数组实时变;action=y×9+x 逐位算术展开 |
| 2 视角 | 同一句「堵活三」,黑白要学两遍? | 视角开关:符号整盘翻转动画(canonical) |
| 3 三张平面 | 一张 ±1 面哪里不够? | 正负抵消计算器:改模板位置,亲手算出「己敌己=1 < 己空己=2」 |
| 4 模板 | 怎么白送它「三连要堵」? | 3×3 滑窗:拖位置看 9 个乘积与和;扫出嫌疑地图;再看真模型第一层 48 张真模板 |
| 5 叠层 | 单层只看 3×3,怎么看见全盘? | 层深滑杆:视野 +2/层到 15×15;真模型各层特征图逐层点亮 |
| 6 双头 | 81 格分数和 1 个数怎么一起答? | 自由摆子,真前向:摆任意局面,跑真权重出 81 分热图 + 估值 |
| 7 搜索 | 第一印象会错,怎么再想四十遍? | 单步模拟器(选/展/回三键):真模型当叶评估器,树生长、Q/U 跳动,亲手撞见「搜索发现裸网看不见的赢棋」 |
| 8 飞轮 | 数据从哪来、怎么变成棋力? | (s,π,z) 解剖 + 损失计算器(拖 v/z 看罚分)+ 8 对称变换台 |
| 9 竞技场 | 损失降了就等于变强? | 晋升计算器(6:0 vs 34% 运气线)+ 真实颜色偏置数据自己读 |
| 毕业沙盒 | —— | 和真模型下一盘(真 MCTS+真权重)+ 全系统图(点击跳回教它的那一课) |

课程骨架 = learn 四卷决策链逐条拆进关卡;公式全部转成可操作部件。

## 每课节拍(卡→通)

1. **谜题**:开头 30 秒一个问题,读者先选答案(承诺装置,错没关系);
2. **揭晓**:短段落讲机制,术语首现即定义,一句不超过一个新概念;
3. **部件**:读者亲手操作机制(拖、摆、单步——不是看动画);
4. **对账**(折叠区):锚到 `alphagomoku/*.py L##`,想读真码的自己展开;
5. **小测**:2~3 题,过关解锁下一课(localStorage 记进度)。

## 真实性管线(命根)

- `learn/scripts/export-weights.py`(.venv torch):导出 `best.pt` + `iter_000000.pt`(未训练对照)为 JSON(≈1MB,权重取 4 位小数)→ 打包进站;
- `learn/scripts/export-data.mjs` 沿用 explainer 已验证模式:导真实对局 / metrics.jsonl / arena 战报 → `src/data/real.ts`;
- **TS 前向引擎**(`src/engine/`):encode / conv / BN(推理态,running stats)/ ReLU / FC / tanh / softmax / log_softmax 直写,镜像 `model.py`;
- **TS MCTS 引擎**:镜像 `mcts.py`(PUCT、逐层取负、终局直传、根噪声、访问数);
- **正确性铁闸**:python 端对固定输入集导出期望输出,node 测试逐张量断言(容差 1e-4)。引擎对拍不过,站不许交付;
- 诚实约定:真数据标「第 N 轮真实对局」,教学简化处图注声明。
