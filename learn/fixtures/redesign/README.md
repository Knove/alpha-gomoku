# 训练链基准输出

本目录保存一份固定随机种子、最小预算的训练链基准输出,它是设计方案迁移路线阶段 0 要求的基准输出文件,供验收判据四(数字随码可核)对拍:日后课文新增的读数句与粘贴输出,其中的每个数字都应能与本目录的文件逐字对上。

## 生成命令

```
.venv/bin/python learn/fixtures/redesign/make_baseline.py
```

脚本在系统临时目录中完整运行一遍训练链,运行参数为固定随机种子 42(演示配置 configs/fast.json 中已固定)、演示配置 configs/fast.json、最大轮数 1;运行目录不写入 data/runs,脚本结束后自动清理。运行结束后,脚本把小体积输出拷回本目录。

## 文件清单

- `metrics.jsonl`:第 0 轮的指标记录,从运行目录原样拷贝。一行记录含总损失、策略损失、价值损失、学习率、对局数、样本数、回放池规模与受控对战结果。
- `status.json`:训练结束时的状态摘要,从运行目录原样拷贝。
- `game-head.jsonl`:第 0 轮第一局棋的自我对弈记录节选。第一行是局记录头,含对局编号、结果、总手数与保留手数;其后 5 行是前 5 手,每手含手数、落点、行棋方、价值估计、访问分布 π(81 个落点各一项)与访问数最高的 5 个落点。原对局共 41 手,只保留前 5 手以控制体积。
- `make_baseline.py`:重新生成上述三个文件的脚本,内容即上面的生成命令。

## 是否降级

未降级。完整训练链一轮(12 局棋的自我对弈、一次训练步、6 局棋的受控对战)在本机十余秒跑完,因此按原计划保存完整一轮的输出,没有降级为「一次自我对弈加一次训练步」的最小链路。

## 对拍口径

与墙钟时间有关的字段不参与对拍:指标记录的 `ts`、`sec_selfplay`、`sec_train`,状态摘要的 `heartbeat` 与 `pid`,局头的 `created_at`。其余字段逐字对拍。生成脚本已核对:除上述字段外,本轮输出与 data/runs/demo 既有运行的第 0 轮记录完全一致,可判定为同种子可复现。
